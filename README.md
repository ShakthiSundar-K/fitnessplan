# Divya Fit Plan 💪

A mobile-first React app with Divya's 16-week fat-loss plan (66 kg → 58 kg).

- **Today**: progress, meal tick-off with kcal/protein/fiber rings, water tracker, daily habits
- **Meals**: Mon–Sun plan with 6 swappable options per meal, plus the full catalog for every slot
- **Train**: Push / Pull / Legs / Full-body split with 4 progressive phases, set tracking, rest timer, cardio
- **Recipes**: 60+ recipes with search and filters (air fryer, high fiber, veg, prep-ahead…)
- **Divya**: weight log + chart, rules, gut-health tips, grocery list

All data is saved on the device (localStorage). No pineapple, no leafy greens, no plain boiled eggs.

## Run

```bash
npm install
npm run dev
```

On iPhone: open in Safari → Share → **Add to Home Screen** for a full-screen app.

## Build

```bash
npm run build   # output in dist/
```
